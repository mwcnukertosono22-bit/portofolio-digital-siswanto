Tiga hambatan di sekolah binaan Lengkong

Motivasi guru sudah tinggi. Hambatannya bukan teknologi, melainkan keyakinan bahwa mereka mampu membuat media sendiri.

Kesenjangan keterampilan

Guru menganggap membuat aplikasi harus bisa koding.

Kejenuhan pembelajaran

IPA berpola hafalan, seperti fotosintesis, membuat siswa cepat jenuh.

Kebutuhan solusi praktis

Media harus mudah dijalankan di perangkat sekolah tanpa instalasi.

Karya: model pembinaan dan game

Satu file HTML

React 18, Babel, Tailwind via CDN. Kurang dari 1 MB.

Dua tim

Dino hijau (Tim A) melawan Dino merah (Tim B).

60 soal IPA

Fotosintesis, 3 kategori, format JSON, jawaban diacak.

Multimedia

Animasi, musik latar, efek suara, fanfare.

Tata letak layar permainan

Soal 15%
Arena tarik tambang 60%

Langkah pengembangan

Guru dilatih berpikir seperti perancang game, bukan menghafal sintaks.

Splash Screen

Intro 6 detik dengan zoom-in identitas pembuat.

Title Screen

Judul, musik latar, tombol “MASUK”.

Menu Utama

Prompt yang dipakai membangun aplikasi

Bertindaklah sebagai Senior Game Developer. Buatkan game edukasi 2 Pemain ‘Dino Tug of War’ dalam SATU FILE HTML menggunakan React 18, Babel, dan Tailwind CSS via CDN. Gunakan aset gambar Dino Kiri (Hijau), Dino Kanan (Merah), serta audio BGM/SFX. Terapkan logika tarik tambang: posisi awal 50, benar = geser 5 poin, salah = tombol terkunci 5 detik. Acak posisi pilihan jawaban dan sediakan struktur JSON untuk 60 soal IPA Fotosintesis.

Lima unsur prompt. Pilih satu untuk menyorotnya:
